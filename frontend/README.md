# TODO App - Frontend

React + Vite + TypeScript frontend.

## Setup

```bash
npm install
```

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Run in development mode |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm test` | Run Jest tests |

## Development

```bash
npm run dev
# Opens at http://localhost:5173
```
